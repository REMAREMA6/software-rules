# Research References

**Maturity:** Draft  
**Research date:** 2026-11-26

This bibliography records the primary sources used for Phase 1. Versions and publication statuses are stated as observed on the research date. Drafts and community-group reports must not be described as final international or W3C standards.

## Requirements engineering and modelling

1. **ISO/IEC/IEEE 29148:2018 — Systems and software engineering — Life cycle processes — Requirements engineering.** Edition 2, published November 2018; confirmed in 2024. ISO lists Edition 3 as a Draft International Standard under development, in the enquiry phase as of 2026-11-26.  
   https://www.iso.org/standard/72089.html  
   https://www.iso.org/standard/94091.html

2. **OMG Model Driven Architecture (MDA) — Overview and FAQ.** Explains Platform-Independent Models (PIMs) and Platform-Specific Models (PSMs).  
   https://www.omg.org/mda/specs.htm  
   https://www.omg.org/mda/faq_mda.htm

3. **OMG Unified Modeling Language (UML), Version 2.5.1.** Adopted December 2017; includes normative specification and machine-readable XMI metamodel documents.  
   https://www.omg.org/spec/UML  
   https://www.omg.org/spec/UML/2.5.1

4. **OMG Semantics of Business Vocabulary and Business Rules (SBVR), Version 1.5.** Adopted December 2019; includes normative machine-readable XMI-related artifacts.  
   https://www.omg.org/spec/SBVR  
   https://www.omg.org/spec/SBVR/1.5

## API and protocol contracts

5. **OpenAPI Specification, Version 3.2.1.** Dated 10 September 2026.  
   https://spec.openapis.org/oas/v3.2.1.html  
   https://spec.openapis.org/oas/

6. **AsyncAPI Specification, Version 3.1.0.** Event-driven and message-based API description.  
   https://www.asyncapi.com/docs/reference/specification/v3.1.0  
   https://www.asyncapi.com/docs/concepts/asyncapi-document

7. **RFC 9110 — HTTP Semantics.** June 2022; IETF Internet Standards Track.  
   https://www.rfc-editor.org/rfc/rfc9110.html

## Runtime observability

8. **OpenTelemetry — Semantic Conventions.** Common names for operations and data across traces, metrics, logs, profiles, and resources.  
   https://opentelemetry.io/docs/concepts/semantic-conventions/  
   https://opentelemetry.io/docs/specs/semconv/  
   https://opentelemetry.io/docs/specs/semconv/general/trace/  
   https://opentelemetry.io/docs/specs/semconv/general/events/

9. **OpenTelemetry — Tracing API.** Defines spans, context propagation, timestamps, attributes, events, links, and status.  
   https://opentelemetry.io/docs/specs/otel/trace/api/

## Web and native interface inspection

10. **WHATWG DOM Standard.** Defines the DOM programming model and document tree concepts.  
    https://dom.spec.whatwg.org/

11. **W3C CSS Object Model (CSSOM).** Reviewed publication is a W3C Working Draft dated 26 August 2021. Section 9 describes resolved values returned by getComputedStyle(). Check current status before relying on it as a stable normative dependency.  
    https://www.w3.org/TR/cssom-1/

12. **W3C WebDriver.** Reviewed publication is a W3C Working Draft dated 9 November 2026. Defines a platform- and language-neutral remote-control interface for browser introspection and control.  
    https://www.w3.org/TR/webdriver2/

13. **W3C Accessible Rich Internet Applications (WAI-ARIA) 1.2.** W3C Recommendation, 6 June 2023.  
    https://www.w3.org/TR/wai-aria-1.2/

14. **AndroidX Test UI Automator — UiObject2 API reference.** Documents native Android UI object inspection including parent, text, content description, visible bounds, and drawing order.  
    https://developer.android.com/reference/androidx/test/uiautomator/UiObject2

## Scenario-based specification

15. **Cucumber — Gherkin Reference.** Documents Given/When/Then scenario structure and the relationship between scenarios, step definitions, and executable specifications.  
    https://cucumber.io/docs/gherkin/reference/

## Machine validation and design tokens

16. **JSON Schema — Draft 2020-12.** Published 16 June 2022. Defines Core and Validation specifications and associated vocabularies.  
    https://json-schema.org/draft/2020-12/  
    https://json-schema.org/draft/2020-12/json-schema-core.html  
    https://json-schema.org/draft/2020-12/json-schema-validation.html

17. **Design Tokens Community Group — Design Tokens Format Module 2025.10.** Final Community Group Report, 28 October 2025. Explicitly not a W3C Standard and not on the W3C Standards Track; described by the report as stable and intended for implementation.  
    https://www.designtokens.org/tr/2025.10/format/  
    https://www.w3.org/community/design-tokens/  
    https://www.w3.org/community/design-tokens/2025/10/28/design-tokens-specification-reaches-first-stable-version/
